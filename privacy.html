Hearth

Privacy Policy

Effective November 11, 2026

Hearth is a private, self-hosted household application. One household runs it on its own computer for its own members. It is not offered to the public. This policy explains what Hearth does with data, including data it receives from Google.

Where data lives

Hearth stores its data in an encrypted database on the household's own computer. There is no Hearth company server and no shared cloud account. Encrypted backups may be copied to the household's own Google Drive and to another computer in the home.

Data Hearth receives from Google

Only when the household connects its Google account, and only with these permissions:

  • Gmail (read-only): Hearth reads only the messages under one label the household chooses, to recognize bill statements and payment receipts (for example the biller, the amount and the date paid). It never sends, deletes, labels or changes mail, and it does not read messages outside that label.
  • Google Calendar (read-only): Hearth reads events from one calendar the household picks, to show family dates.
  • Google Drive (only files Hearth creates): Hearth stores the household's encrypted backups. It cannot see or open any other file in the Drive.

How that data is used

  • Message text and attachments are processed on the household's own computer and are not sent to any other party.
  • Hearth may use details derived from them, such as an amount, a date or which bill was paid, in its own features for the same household, including its assistant. The assistant uses Anthropic's Claude API under Hearth's privacy safeguards: sensitive fields are removed first, and every request is logged where the household can review it. Email text itself is not sent.
  • Google data is never sold, never used for advertising, never shared with data brokers, and never used to train artificial intelligence or machine learning models.
  • No person other than the household's own members reads it.

Hearth's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and deleting data

Data stays on the household's computer for as long as the household uses Hearth. The household can disconnect Google at any time at myaccount.google.com/permissions. Hearth then stops reading Gmail and Calendar and stops writing to Drive. Data Hearth stored can be deleted by the household at any time, and on request through the contact link below.

Security

The database is encrypted at rest, secrets are kept in the operating system's credential store, backups are encrypted before they leave the computer, and the app is reachable only on the household's private network.
